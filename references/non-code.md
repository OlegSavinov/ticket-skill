# Non-code tickets (research, decisions)

- No git repo: skip `L`; keep the event log in chat and give the score at the retro.
- Map stages: explore → parallel research agents; specs → an acceptance checklist; diff → the findings.
- Gate 1 also asks: what counts as evidence (real data only? which area/sources?), hard
  must-haves, no-gos (including other people with a veto), and how the budget is defined.
- Every agent brief carries the evidence rule; facts need a source URL; no estimates unless allowed.
- Eligibility or coverage claims (warranty, settlement, rebate) stay "unverified" until
  checked against the user's exact item (VIN, serial, account).
- Stage 7: recompute every bottom-line number; it must include every cost the plan named.
